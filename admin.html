Entrar no painel

Cole o código de acesso (token) do GitHub para editar os produtos do catálogo.

Como gerar o token (uma vez só)
  1. No GitHub, clique na sua foto no canto de cima e depois em Settings.
  2. No fim do menu da esquerda, clique em Developer settings, depois Personal access tokens e Fine-grained tokens.
  3. Clique em Generate new token. Dê um nome (por exemplo, "Painel StudioPrint") e escolha a validade (por exemplo, 1 ano).
  4. Em Repository access, escolha Only select repositories e marque studio-print.github.io.
  5. Em Permissions, adicione Contents com acesso Read and write.
  6. Clique em Generate token, copie o código (começa com github_pat_) e cole aqui.

O token fica guardado só neste aparelho. Ele dá acesso apenas ao repositório do catálogo. Não mande para ninguém: quem tiver o token consegue mudar o site.

Falta um passo para usar os pedidos

Os pedidos têm nome, telefone e endereço dos clientes, então eles ficam num repositório privado, separado do site, que só vocês veem.

  1. No GitHub (conta Studio-print), clique em + no canto de cima e em New repository.
  2. Nome: studioprint-pedidos. Marque Private e também Add a README file. Clique em Create repository.
  3. Vá em Settings > Developer settings > Personal access tokens > Fine-grained tokens e abra o token do painel.
  4. Clique em Edit. Em Repository access, adicione studioprint-pedidos (deixe o studio-print.github.io marcado também) e salve. A permissão Contents: Read and write vale para os dois.
  5. Volte aqui e toque no botão abaixo. A senha do painel continua a mesma.

O número não vem dentro da mensagem: copie do topo da conversa. Se o cliente já comprou antes, o painel completa sozinho.
